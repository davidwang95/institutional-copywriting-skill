## Official skill documentation

- [OpenAI: Build skills](https://learn.chatgpt.com/docs/build-skills) — current skill structure, discovery paths, explicit invocation, and optional resources. The [Codex skills URL](https://developers.openai.com/codex/skills/) redirects here.
- [Anthropic: Claude Code skills](https://code.claude.com/docs/en/skills) — project and personal paths, slash-command invocation, frontmatter, and supporting files.
- [Anthropic: Agent Skills overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) — skill metadata and progressive disclosure.
- [Agent Skills specification](https://agentskills.io/specification) — portable directory structure and metadata constraints.
- [OpenAI: Testing Agent Skills with Evals](https://developers.openai.com/blog/eval-skills) — evaluation through prompts, traces, outputs, and checks. Its older installation-path examples are superseded by the current Build skills page.
